The engine reads LaTeX as LaTeX writes it.

## Features

- Packages, classes, languages and links, and TeX's own rules
- Commutative diagrams, circuits and trees, with TikZ matrices, edges and baselines

## Changes

- Every name in the code is one word, with one verb per job
- Code nothing runs is removed
- A C++26 profile for IDEs
