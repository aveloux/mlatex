The first prototype: a TeX engine that reads a document and sets it into pages, with no primitives or packages yet.

## Features

- A TeX core: catcodes, a lexer and an expression parser
- A layout system of boxes and glue, with a paragraph line breaker
- A typography module that loads fonts, caches faces and shapes text
- Hyphenation with the official patterns from CTAN
- A typesetter that turns the layout into pages
- The structure of PDF and WebAssembly output, with WebAssembly builds that need no fontconfig
- Unix builds alongside Windows, checked by a CMake workflow on GitHub Actions

## Fixes

- The line breaker no longer loops forever
- Catcodes and the expression parser read their input correctly
