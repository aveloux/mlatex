A working expander, rebuilt on a primitive layer of its own, inside a sandbox.

## Features

- A primitive layer built from scratch: blocks, macros, values, arithmetic, loops and the full \if family
- Constant-time symbol dispatch, with \global kept constant-time too
- A traceback of errors per module, merged on demand
- A sandbox: an allocator with a byte ceiling, a policy that denies host access by default, and a VM that runs a document from a string or a file
- Reference documentation with Doxygen, built by an opt-in docs target

## Fixes

- Multi-digit numbers, octal and hexadecimal constants and units read correctly
- The lexer emits \par again, so the parser can recover from errors
- A comment swallows its line ending
- A self-referential macro stops at the expansion limit instead of spinning forever
- \global survives the end of a group
- The expression parser keeps the token after every formula
- The lexer and expansion tests pass again
