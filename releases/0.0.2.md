Syntax trees now reach the page, and the engine gains its first primitives and macros.

## Features

- A translation layer that turns the syntax and expression trees into layout
- A font cache, arena allocators and profile-guided optimisation, for documents set in under 15 ms
- Core primitives and macro support, with formulas parsed as expressions
- A Code of Conduct and a security policy

## Fixes

- Faster line breaking: the breaker works on candidates and no longer calls std::pow
- A deadlock when a font face was move-assigned, and a native handle the font registry leaked
- Duplicate thread-local symbols when linking with MinGW
