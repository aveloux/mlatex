The engine as packages for JavaScript and Python, released by GitHub Actions.

## Features

- A JavaScript package, `mlatex`: the WebAssembly module with a Node entry, types and a README, attached here as `mlatex-0.1.2.tgz`
- Python wheels, `mlatex`, for Windows, macOS and Linux on x64 and ARM64, carrying the C library and its fonts for `ctypes`, attached here
- An error names the file it is in: `appendix.tex:3:5: error (macro): Undefined control sequence \foo`
- Releases are made by GitHub Actions from what the Build workflow tested

## Fixes

- `latex_ffi.dll` loads its JPEG and WebP libraries from its own folder, so a program that loads it from elsewhere, as Python does, no longer stops at its first picture
- `\evaluate` answers powers of 0, 1 and -1 at once
- `\numexpr` holds its products within 64 bits
- `\foreach` counts its ranges in whole steps

## Changes

- The primitives are grouped into clusters, each its own namespace, named for what they stand for
- Every struct field is named with a word, and text is written with `std::format`

## Known issues

- The installers are named 0.1.0, and `mlatex --version` says 0.1.0: this release came just before the `VERSION` file that now names every package
